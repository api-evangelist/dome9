Dome9, acquired by Check Point in 2018 and now sold as Check Point CloudGuard, provides cloud security posture management and compliance across AWS, Azure, Google Cloud, Alibaba Cloud, Kubernetes and container registries. Its v2 REST API at api.dome9.com is a large, genuinely public surface — 601 paths and 722 operations described by a first-party Swagger 2.0 contract the API host serves itself — covering cloud-account onboarding, compliance rulesets and assessments, posture findings and alerts, security groups and firewall policy, just-in-time access leases, users, roles and service accounts, plus outbound delivery of findings to webhooks, SNS, Slack, Teams, ITSM systems and the AWS/Azure/GCP native findings sinks.

**Areas:** Cloud Security · Compliance · Infrastructure Security · Multi-Cloud · Security Posture Management

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Dome9: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
